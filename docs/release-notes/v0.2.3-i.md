# Hermes v0.2.3-i

Hermes v0.2.3-i adds AI Small Tool support with customizable AI shortcuts and local file integration.

## Download

Download:

```text
Hermes-v0.2.3-i-win-x64-portable.zip
````

Unzip it and run:

```text
Hermes.Windows.exe
```

This is a `win-x64 self-contained` portable build. You do not need to install .NET Runtime separately.

## Highlights

* Added AI Small Tool (AI Actions).
* Added custom AI actions with configurable name, hotkey, and Prompt template.
* Added Prompt variables:

  * `$text$` for selected text.
  * `$clipboard$` for clipboard content.
  * `$file_input$` for local file input.
* Added AI output file operations:

  * `$file_append$` appends results to the source file.
  * `$file_overwrite$` overwrites the source file.
* Added DeepSeek and OpenAI-compatible API support.
* Added AI Action management in Settings.
* Added hotkey recording for AI Actions.

## Fixes

* Fixed AI Action configuration path.
* Fixed input files being copied or renamed instead of using the original source file.
* Fixed file write-back targeting the wrong directory.
* Fixed AI Actions incorrectly depending on the original translation API workflow.

## Known Limitations

* AI Actions currently support text-based AI models only.
* Image input and multimodal models are not supported.
* Supported file inputs are text files such as `.md` and `.txt`.
* The app is not code signed yet, so Windows SmartScreen may show an unknown publisher warning.
* Current release is a portable package, not a full installer.
